# V2bX v1.12.1 — به‌روزرسانی هستهٔ MDNS و کاهش هزینهٔ پردازش سرور

این نسخه تمام تغییرات v1.12.0 را نگه می‌دارد و هستهٔ داخلی MasterDnsVPN را به
[android-multiuser-20261031](https://github.com/PoriyaVali/MasterDnsVPN/releases/tag/android-multiuser-20261031)
به‌روزرسانی می‌کند.

نسخهٔ دقیق وابستگی: `v0.0.0-20261031181923-1a73a5ad59f4`، از commit
[`1a73a5ad59f492addb7a85e61c3761a02921968b`](https://github.com/PoriyaVali/MasterDnsVPN/commit/1a73a5ad59f492addb7a85e61c3761a02921968b).

## تغییرات

- هزینهٔ پردازش نام DNS، ساخت آدرس کلاینت و خواندن وضعیت ARQ کاهش یافته است.
  این تغییرات تخصیص حافظه و گرفتن قفل در مسیر پردازش بسته را کمتر می‌کنند.
- قالب بسته، رمزنگاری و احراز هویت تغییر نکرده‌اند؛ برای دریافت بهبود سمت سرور،
  به‌روزرسانی کلاینت‌ها لازم نیست.
- مدیریت کاربران، محدودیت دستگاه، ثبت مصرف و انتقال مصرف هنگام بارگذاری دوبارهٔ
  نود از طریق همان هستهٔ مدیریت‌شدهٔ MDNS در V2bX انجام می‌شود.

در این انتشار درصد ثابت کاهش CPU یا افزایش سرعت روی شبکهٔ واقعی ادعا نمی‌شود.
نتایج قبلیِ benchmark تک‌مسیره را نباید به بار چندمسیره یا تمام سرورها تعمیم داد.

## ارتقا

پس از انتشار عمومی این نسخه، روی سرور نود با دسترسی root:

```sh
v2bx update
```

برای انتخاب صریح نسخه:

```sh
v2bx update 1.12.1
v2bx version
```

برگشت به نسخهٔ قبلی:

```sh
v2bx update 1.12.0
```

فرمان update از آخرین انتشار عمومی `PoriyaVali/V2bX` استفاده می‌کند؛ تغییر
تنظیمات پنل یا کاربران برای این به‌روزرسانی لازم نیست.

## اعتبارسنجی

- سورس دقیق MasterDnsVPN در `go.mod` ثابت و checksum آن در `go.sum` ثبت شده است.
- آزمون‌های هستهٔ MDNS با race detector، سه بار موفق بودند؛ شامل آدرس گوش‌دادن،
  نگاشت کاربران چند نود، شمارش دستگاه و انتقال مصرف هنگام بارگذاری دوبارهٔ نود.
- `go vet` برای هستهٔ MDNS، API پنل و limiter موفق بود.
- ساخت Linux amd64 با تمام tagهای انتشار، Go 1.27.1 و `jsonv2` موفق بود؛ metadata
  باینری، قرارگرفتن نسخهٔ دقیق جدید MasterDnsVPN در آن را تأیید کرد. این بررسی محلی
  روی Windows انجام شد و باینری Linux در آن اجرا نشد.
- انتشار عمومی به موفقیت اعتبارسنجی workflow انتشار و ساخت تمام ۲۲ هدف وابسته است؛
  پیش از پایان ساخت‌ها، نسخه به‌عنوان latest در دسترس update قرار نمی‌گیرد.

این نتایج آزمون دستگاه یا سرور عملیاتی و اندازه‌گیری جدید کارایی روی شبکهٔ واقعی نیستند.

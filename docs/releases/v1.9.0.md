# V2bX v1.9.0

این نسخه اصلاحات پایداری و هماهنگی پنل، راه‌اندازی خودکار گواهی و تقویت سایت پوششی
را به‌همراه هستهٔ MasterDnsVPN منتشرشده در `android-multiuser-20261023` ارائه می‌کند.

## ارتقا با یک دستور

با دسترسی root روی سروری که V2bX نصب است:

```sh
v2bx update
```

برای انتخاب صریح همین نسخه نیز `v2bx update v1.9.0` قابل استفاده است. دستور بدون
نسخه، آخرین ریلیز کامل GitHub را می‌گیرد. فایل دانلودشده پیش از توقف سرویس بررسی
می‌شود؛ سرویس فعال پس از جایگزینی فایل‌ها دوباره شروع و پایداری فرایند بررسی می‌شود.
در شکست نصب یا بررسی پایداری، مسیر بازگردانی نسخهٔ قبلی اجرا می‌شود. این بررسی،
دسترسی همهٔ نودها از شبکهٔ کاربران را تضمین نمی‌کند.

فایل‌های موجود `/etc/V2bX/config.json`، `dns.json`، `route.json` و گواهی‌ها حفظ
می‌شوند. سرویس خاموش خودکار روشن نمی‌شود. هنگام restart کوتاه، اتصال‌های باز ممکن
است نیاز به اتصال مجدد داشته باشند.

## تغییرهایی که با ارتقا اعمال می‌شوند

- تأیید صحیح رسید گزارش Irboard، نگه‌داشتن گزارش‌های بدون تأیید در صف موجود و کاهش
  تخصیص حافظه هنگام ساخت گزارش ترافیک. پاسخ‌های پنل سقف حجم دارند و دادهٔ ناقص،
  وضعیت سالم کش را جایگزین نمی‌کند.
- پاک‌کردن آدرس کاربران قطع‌شده در هسته‌هایی با snapshot کامل اتصال؛ خطای ساخت
  هستهٔ جایگزین، نودهای فعال را پیش از بررسی تنظیمات خاموش نمی‌کند.
- مدیریت امن‌تر فایل و حساب ACME، بررسی محلی گواهی قبل از موعد تمدید و cache گواهی
  در هستهٔ اختصاصی Hysteria2 و سایت HTTPS همراه.
- سایت پوششی دارای صفحات واقعی، ETag ثابت بر اساس محتوا، gzip از پیش ساخته‌شده و
  سقف درخواست‌های عمومی؛ این سهمیه روی ترافیک کاربران احرازشده اعمال نمی‌شود.
- سایت HTTPS روی TCP همان IP و شمارهٔ پورت نودهای UDP پشتیبانی‌شده، در صورت فعال
  بودن سایت خودکار و آزاد بودن پورت TCP. پورت اشغال جایگزین نمی‌شود و UDP ادامه
  می‌دهد. حذف نود، سایت همراه را نیز می‌بندد.

## قابلیت‌های اختیاری

ویزارد تازه با `V2bX configure` یا گزینهٔ ۹ منو در دسترس است؛ اجرای update آن را
روی تنظیمات موجود اجرا نمی‌کند. ویزارد، پنل، کلید API و فهرست `type:id` را می‌گیرد
و TLS/REALITY، دامنه و هستهٔ مناسب را از API تعیین می‌کند. در حالت خودکار،
VLESS بدون رمزگذاری افزوده و Trojan روی TCP+TLS برای fallback وب به Xray می‌روند.
انتخاب هستهٔ نودهای فعلی هنگام update تغییر نمی‌کند.

برای سایت اختصاصی از `--cover-root /var/www/node-public` و برای خاموش‌کردن شنوندهٔ
TCP همراه از `Decoy.ServeTCP: false` استفاده کنید. نسخه‌های قدیمی پنل که hostname/SNI
کافی نمی‌فرستند، هنگام ساخت تنظیمات تازه به ورود دامنه یا `--cert-domain` نیاز دارند.
صدور خودکار گواهی به DNS درست و مسیر اعتبارسنجی HTTP-01 یا دسترسی DNS-01 نیاز دارد.

## سازگاری و اعتبارسنجی

پروتکل و رمزگذاری MDNS در این ریلیز نسبت به v1.8.2 تغییر نکرده است؛ همان نسخهٔ
هسته جاسازی شده است. ارتقای کلاینت MDNS برای نصب این نسخهٔ V2bX لازم نیست.
تنظیمات TLS، REALITY، fallback و masquerade سفارشی حفظ می‌شوند.

بررسی‌ها شامل بیلد کامل با تگ‌های ریلیز، vet، Race، آزمون‌های نصب و بازگردانی،
قرارداد واقعی Irboard، اجرای باینری با ویزارد و TLS معتبر آزمایشی، HTTP/2 و HTTP/3
و انتقال کاربر معتبر هنگام پرشدن سهمیهٔ سایت هستند. یک race از پیش موجود در تعویض
گواهی وابستگی Xray باقی است؛ آزمون‌های مربوط به TLS فایل آن جداگانه بدون Race اجرا
می‌شوند. صدور Let's Encrypt واقعی و آزمون میدانی GFW در این محیط انجام نشده است.

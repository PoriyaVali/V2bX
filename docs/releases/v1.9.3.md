# V2bX v1.9.3 — اصلاح شناسایی، تمدید و بارگذاری گواهی‌ها

این نسخه چرخهٔ گواهی در Sing، Xray، Hysteria2 و TrustTunnel را اصلاح می‌کند.

- دامنه/SAN، تاریخ اعتبار، تطابق کلید و کاربرد TLS Server بررسی می‌شوند؛
  جایگزینی نامعتبر گواهی سالم را کنار نمی‌زند و پس از اصلاح فایل بازیابی انجام می‌شود.
- حساب ACME حفظ می‌شود. گواهی مدیریت‌شده از ۳۰ روز مانده به انقضا، با بررسی
  هر ۶ ساعت تمدید می‌شود. تعارض مالکیت مسیر گواهی پیش از شروع رد می‌شود.
- Sing: رفع تداخل هم‌زمانی TLS و بارگذاری هماهنگ گواهی/کلید.
- Xray: رفع توقف دائمی بارگذاری پس از خطای موقت فایل و تداخل هم‌زمانی گواهی.
- Hysteria2: اصلاح نوع گواهی، مسیرهای دارای `{domain}` و بارگذاری مشترک QUIC/TCP.
- TrustTunnel: افزودن تمدید و پایش فایل، snapshot معتبر گواهی/کلید و صف امن reload؛
  رعایت آدرس شنود، رد نوع گواهی ناشناخته و حذف اطلاعات ورود ثابت اولیه.
- ساخت باینری و Docker از patchهای وابستگی دارای هش و منشأ مشخص استفاده می‌کند؛
  نسخهٔ اصلی `go.mod` و `go.sum` تغییر نکرده است.

برای ارتقا با دسترسی root:

```sh
v2bx update 1.9.3
```

در حالت `file/provided`، صدور و تمدید همچنان بر عهدهٔ ابزار بیرونی است؛ V2bX
فایل جدید معتبر را بارگذاری می‌کند. رفع مقدار نادرست `CertDomain` قبلی، مطابق
[راهنمای v1.9.2](v1.9.2.md)، ممکن است به اجرای ویزارد نیاز داشته باشد.
TrustTunnel از hostname تنظیمات خودش استفاده می‌کند و به endpoint بومی نیاز دارد.

آزمون‌های محلی پیش از انتشار: ۱۲ بسته با Race موفق؛ ۵۷۵ نتیجهٔ موفق با احتساب
زیرآزمون‌ها، ۴ مورد skip و بدون شکست. اتصال واقعی و تعویض سریال گواهی در TLS/QUIC
برای Sing، Xray و Hysteria2 بررسی شد. طبق درخواست مالک، هنگام انتشار تست‌ها دوباره
اجرا نمی‌شوند. اجرای واقعی endpoint بومی TrustTunnel روی لینوکس، صدور/تمدید عمومی
HTTP-01 و DNS-01 و OCSP هنوز تأیید نشده‌اند؛ این محدودیت‌ها با موفقیت ساخت رفع نمی‌شوند.

جزئیات فنی، خطاهای ثبت‌شده و محدودیت‌ها در
[گزارش چرخهٔ گواهی](../certificate-lifecycle-audit-2026-10-24.md) آمده است.

For source builds, first run `python3 scripts/prepare_tls_dependencies.py --allow-download`
and pass its `audit_mod` as `go build -mod=readonly -modfile=...`. The release and
Docker builds do this explicitly; plain Go builds select the original dependencies.

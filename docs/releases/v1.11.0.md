# V2bX v1.11.0

Adds all changes from [PR #23](https://github.com/PoriyaVali/V2bX/pull/23) after v1.10.1:

- Managed Sudoku and Snell nodes on the Mihomo core, including per-user authentication, TCP/UDP traffic accounting, online reports, speed and device limits, panel rules, bans, expiry and quota handling.
- Live membership changes preserve other subscribers' connections. Sudoku derives each subscriber's split key from their UUID; Snell uses a distinct PSK per user with ShadowTLS v3.
- Panel API decoding, guided configuration, protocol filtering advice and full-stack audit support for both node types.
- Internal handshake and fallback connections are restricted to the node's configured endpoints and kept outside subscriber accounting.
- Pins the Mihomo fork containing its managed Sudoku and Snell listeners, also released as [v1.19.32-dm5](https://github.com/PoriyaVali/mihomo/releases/tag/v1.19.32-dm5).

Snell requires ShadowTLS v3 mode and a configured handshake host. Existing configurations remain supported.

Implementation: Claude's PR commits; this release merges and packages them. Existing PR builds for all 22 platforms, race/vet checks and both Docker architectures were successful. At the owner's request, tests were not rerun for this release. Binaries embed v1.11.0 and are published only after every build uploads its archive and digest.

Prior author-reported full-stack audit: 371/373 checks passed; two MDNS checks encountered the same environment address clash reported for v1.10.1. MDNS code is unchanged by this release. This audit was not rerun.
